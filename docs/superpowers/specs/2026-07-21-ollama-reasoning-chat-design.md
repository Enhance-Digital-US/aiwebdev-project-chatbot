# Ollama Reasoning Chat + TanStack Router Design

## Overview

Add a second chat example that connects to a local Ollama model (gemma4:12b) with reasoning trace display using AI Elements. Introduce TanStack Router to navigate between chat examples, with an index page as a hub.

## Routing

| Route | Component | Description |
|-------|-----------|-------------|
| `/` | Index | Links to all chat examples |
| `/openai-chat` | OpenAIChat | Existing OpenAI chat (extracted from App.tsx) |
| `/ollama-chat` | OllamaChat | Local Ollama chat with reasoning display |

Uses TanStack Router (`@tanstack/react-router`) with file-based route convention in `src/routes/`.

## Backend

### New Route: `POST /api/ollama-chat`

Added to `packages/backend/src/index.ts` alongside the existing `/api/chat` route.

- Uses `ollama-ai-provider-v2` with `createOllama({ baseURL: 'http://localhost:11434/api' })`
- Calls `streamText` with `providerOptions: { ollama: { think: true } }` to enable reasoning for gemma4:12b
- Returns `createUIMessageStreamResponse` with `toUIMessageStream({ sendReasoning: true })` to forward reasoning parts

### New dependency

- `ollama-ai-provider-v2` — community AI SDK provider for Ollama

### Ollama Chat Component

Same chat structure as OpenAI but with reasoning display:

```tsx
// In message rendering loop:
message.parts.map((part, i) => {
  if (part.type === "reasoning") {
    return (
      <Reasoning key={i} isStreaming={status === "streaming"}>
        <ReasoningTrigger />
        <ReasoningContent>{part.text}</ReasoningContent>
      </Reasoning>
    );
  }
  if (part.type === "text") {
    return <MessageResponse key={i}>{part.text}</MessageResponse>;
  }
})
```

The `<Reasoning>` component auto-opens while streaming and collapses when the response finishes.

## Data Flow (Ollama Chat)

```
User types message
    ↓
PromptInput → sendMessage({ text })
    ↓
useChat({ transport: DefaultChatTransport({ api: '/api/ollama-chat' }) })
    → POST /api/ollama-chat { messages }
    ↓
Hono route handler
    → streamText({
        model: ollama('gemma4:12b'),
        providerOptions: { ollama: { think: true } },
        messages
      })
    → toUIMessageStream({ sendReasoning: true })
    ↓
Streamed response with reasoning + text parts
    ↓
useChat receives parts → updates messages
    ↓
<Reasoning> renders thinking trace (collapsible)
<MessageResponse> renders final answer
```

## Prerequisites

- Ollama must be running locally (`ollama serve`)
- gemma4:12b model must be pulled (`ollama pull gemma4:12b`)

## CORS Note

The Ollama route connects to `localhost:11434` from the wrangler dev server (also localhost), so no additional CORS config is needed on Ollama's side. The existing frontend CORS config on the Hono app already allows `http://localhost:5173`.
