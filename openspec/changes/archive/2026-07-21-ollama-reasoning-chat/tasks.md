# Ollama Reasoning Chat + TanStack Router Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Add a second chat example connected to a local Ollama model (gemma4:12b) with reasoning trace display, and introduce TanStack Router for navigating between chat examples.

**Architecture:** Add a `/api/ollama-chat` route to the existing Hono backend using `ollama-ai-provider-v2` with reasoning enabled. On the frontend, replace direct `<App />` mounting with TanStack Router file-based routing: an index page links to `/openai-chat` (extracted from current App.tsx) and `/ollama-chat` (new, with AI Elements `<Reasoning>` component).

**Tech Stack:** TanStack Router (`@tanstack/react-router`, `@tanstack/router-plugin`), `ollama-ai-provider-v2`, AI Elements reasoning component

## Global Constraints

- All packages use latest versions at time of install
- pnpm as the sole package manager
- TypeScript strict mode in all packages
- No `tailwind.config.js` — TailwindCSS 4 uses CSS-based configuration
- AI Elements components install to `src/components/ai-elements/` (shadcn copy model)
- TypeScript 7.0.2 is installed — `baseUrl` is not allowed in tsconfig (removed in TS 7)
- Backend uses `createOpenAI`/`createOllama` (not default exports) because CF Workers lack `process.env`
- Ollama must be running locally on port 11434; gemma4:12b must be pulled

The full file after modification:

```typescript
import { Hono } from "hono";
import { cors } from "hono/cors";
import {
  convertToModelMessages,
  createUIMessageStreamResponse,
  streamText,
  toUIMessageStream,
} from "ai";
import { createOpenAI } from "@ai-sdk/openai";
import { createOllama } from "ollama-ai-provider-v2";

type Bindings = {
  OPENAI_API_KEY: string;
};

const app = new Hono<{ Bindings: Bindings }>();

app.use(
  "/api/*",
  cors({
    origin: ["http://localhost:5173"],
    allowMethods: ["POST"],
    allowHeaders: ["Content-Type"],
  })
);

app.post("/api/chat", async (c) => {
  const openai = createOpenAI({ apiKey: c.env.OPENAI_API_KEY });
  const { messages } = await c.req.json();

  const result = streamText({
    model: openai("gpt-4o-mini"),
    system: "You are a helpful assistant.",
    messages: await convertToModelMessages(messages),
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({ stream: result.stream }),
  });
});

app.post("/api/ollama-chat", async (c) => {
  const ollama = createOllama({ baseURL: "http://localhost:11434/api" });
  const { messages } = await c.req.json();

  const result = streamText({
    model: ollama("gemma4:12b"),
    system: "You are a helpful assistant.",
    messages: await convertToModelMessages(messages),
    providerOptions: { ollama: { think: true } },
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({
      stream: result.stream,
      sendReasoning: true,
    }),
  });
});

export default app;
```

import { createFileRoute } from "@tanstack/react-router";
import { useChat } from "@ai-sdk/react";
import { DefaultChatTransport } from "ai";
import {
  Conversation,
  ConversationContent,
} from "@/components/ai-elements/conversation";
import {
  Message,
  MessageContent,
  MessageResponse,
} from "@/components/ai-elements/message";

  PromptInput,
  PromptInputBody,
  PromptInputFooter,
  PromptInputProvider,
  PromptInputSubmit,
  PromptInputTextarea,

```tsx
import { createFileRoute } from "@tanstack/react-router";
import { useChat } from "@ai-sdk/react";
import { DefaultChatTransport } from "ai";
import {
  Conversation,
  ConversationContent,
} from "@/components/ai-elements/conversation";
import {
  Message,
  MessageContent,
  MessageResponse,
} from "@/components/ai-elements/message";
import {
  Reasoning,
  ReasoningContent,
  ReasoningTrigger,
} from "@/components/ai-elements/reasoning";
import {
  PromptInput,
  PromptInputBody,
  PromptInputFooter,
  PromptInputProvider,
  PromptInputSubmit,
  PromptInputTextarea,
} from "@/components/ai-elements/prompt-input";

export const Route = createFileRoute("/ollama-chat")({
  component: OllamaChat,
});

function OllamaChat() {
  const { messages, sendMessage, status } = useChat({
    transport: new DefaultChatTransport({
      api: "/api/ollama-chat",
    }),
  });

  const handleSubmit = (message: { text: string }) => {
    sendMessage({ text: message.text });
  };

  return (
    <div className="flex-1 flex flex-col">
      <Conversation className="flex-1">
        <ConversationContent>
          {messages.map((message) => (
            <Message key={message.id} from={message.role}>
              <MessageContent>
                {message.parts.map((part, i) => {
                  if (part.type === "reasoning") {
                    return (
                      <Reasoning
                        key={i}
                        isStreaming={status === "streaming"}
                      >
                        <ReasoningTrigger />
                        <ReasoningContent>{part.text}</ReasoningContent>
                      </Reasoning>
                    );
                  }
                  if (part.type === "text") {
                    return (
                      <MessageResponse key={i}>{part.text}</MessageResponse>
                    );
                  }
                  return null;
                })}
              </MessageContent>
            </Message>
          ))}
        </ConversationContent>
      </Conversation>

      <PromptInputProvider>
        <PromptInput onSubmit={handleSubmit} className="border-t p-4">
          <PromptInputBody>
            <PromptInputTextarea placeholder="Type a message..." />
          </PromptInputBody>
          <PromptInputFooter>
            <PromptInputSubmit status={status} />
          </PromptInputFooter>
        </PromptInput>
      </PromptInputProvider>
    </div>
  );
}
```
